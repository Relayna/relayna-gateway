# v1.5.0 release benchmark

The v1.5.0 release candidate requires fresh native amd64 adaptive searches at
5, 10, 20, 40, 80 and 100 MiB, plus a controlled forwarding-latency comparison
against v1.4.0. Release validation is pending. The default deployment has
upload waiting disabled.

Each resource trial uses two fresh pods, two CPUs and 1 GiB of memory per pod,
and a 512 MiB serialized-body budget. The release protocol requires three
fresh-pod confirmations per selected setting. [Benchmark protocol](index.md#required-protocol).

The [separate PR study](https://github.com/sarattha/relayna-gateway/pull/155#issuecomment-6998339170)
measured opt-in waiting with mixed-size JSON on the earlier feature commit.
It includes raw request receipts, process and socket memory, queue deadlines
and a matched LiteLLM comparison.
