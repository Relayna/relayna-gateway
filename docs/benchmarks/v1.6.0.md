# v1.6.0 release benchmark

Release validation is pending. The benchmark will measure the committed
candidate on native arm64 with two fresh Gateway pods per trial. Each pod has
a **2 CPU / 1 GiB** limit and a **512 MiB** serialized-body budget.

```sh
scripts/bench-body-admission --json run --build \
  --body-mib 5 10 20 40 80 100 --repetitions 3 \
  --output target/release-benchmarks/v1.6.0
```

See the [release benchmark protocol](index.md#required-protocol) for the
confirmation and evidence requirements.
